Architecture & Governance

AI reads, code decides.

Large language models extract structured employment intervals from unstructured CV text, while deterministic Python rules compute tenure sums, date overlaps, and profile diffs. Every output is framed as an evidentiary question for the tender committee—never an automated black-box rejection.

1. Structured Extraction AI READS

Parses bidder CV text into employer names, titles and dates copied word for word (anything not in the CV is rejected), start/end dates, and headline claimed years—preserving exact row citations for every extracted field.

2. Deterministic Date & Overlap Math CODE DECIDES

Computes non-overlapping experience durations, flags intersecting employment dates across separate firms, and checks whether total claimed years exceed the listed CV rows.

3. Career-Graph Cross-Check CRUSTDATA API

When a profile URL or bid lookup is supplied, queries career-graph records via the server to compare employer histories, dates, and firm headcount against the bid submission.

4. Committee Clarification Output HUMAN IN LOOP

Outputs numbered, neutral clarification questions linked to exact CV rows and profile entries, along with a ready-to-copy clarification letter and printable report.html.
